## Project Overview

Welcome to the **Deep Learning Masterclass**. 

This repository is a structured, comprehensive educational journey designed to take you from the foundational mathematics of Artificial Intelligence to building modern Deep Learning architectures. 

Deep Learning is not just about writing code; it is about understanding *why* the code works. This masterclass connects the dots between the underlying mathematics, the Python programming foundations, and the practical implementation using PyTorch.

**Who is this for?**
- **Beginners** looking to understand the mathematical intuition behind Neural Networks.
- **Python developers** transitioning into AI and Machine Learning.
- **Students** who want to move beyond high-level APIs and understand how models actually train.
- **Self-paced learners** who want a structured roadmap to follow.

**The Learning Progression:**
The course is designed sequentially. We begin with the essential mathematics (Linear Algebra, Calculus, Gradients), move into Python and data foundations, and then dive deep into Neural Networks, Backpropagation, PyTorch, CNNs, RNNs, and Transformers. 

By combining theoretical video lessons with practical Jupyter Notebooks, this repository aims to provide a complete, hands-on learning experience.

## 🗺️ Complete Course Roadmap

Below is the complete structure of the Deep Learning Masterclass, covering everything from foundational math to advanced neural network architectures.

### 🏗️ FOUNDATION

**Mathematics for AI, ML & Deep Learning**
- Linear Algebra, Vectors, and Matrices
- Matrix Operations and Calculus
- Derivatives, Partial Derivatives, and the Chain Rule
- Gradients and Optimization basics
- Probability and Statistics for Neural Networks

### 🧠 DEEP LEARNING CORE

**Section 01 — Introduction, Learning Roadmap & Setup**
- Introduction to Deep Learning
- AI vs ML vs DL
- How Neural Networks Learn
- Development Environment and Python Setup

**Section 02 — Essential Python, NumPy, Pandas & ML Foundations**
- Essential Python for AI
- NumPy and Pandas for Data Handling
- Basic Machine Learning Concepts (Training/Testing)
- Essential ML Foundations

**Section 03 — Mathematics for Deep Learning**
- Deep dive into Linear Algebra and Calculus
- Chain Rule and Gradients
- Mathematical Intuition for Neural Networks

**Section 04 — Neural Networks, Perceptrons & Forward Propagation**
- Biological vs Artificial Neurons
- Perceptrons, Weights, and Biases
- Neural Network Architecture
- Forward Propagation (Input, Hidden, Output Layers)

**Section 05 — Activation Functions, Loss Functions & Backpropagation**
- Activation Functions: Sigmoid, Tanh, ReLU, Leaky ReLU, GELU, Softmax
- Loss Functions: MSE, Binary Cross Entropy, Categorical Cross Entropy
- The Math of Backpropagation and the Chain Rule

**Section 06 — Gradient Descent, Optimizers & Training**
- Batch, Stochastic, and Mini-Batch Gradient Descent
- Learning Rate and Momentum
- Optimizers: RMSprop, Adam
- Training Loops, Overfitting, and Underfitting

**Section 07 — PyTorch, Data Preparation & Model Evaluation**
- Introduction to PyTorch and Tensors
- Autograd (Automatic Differentiation)
- Dataset and DataLoader
- Building, Training, and Evaluating Neural Networks
- Saving and Loading Models

**Section 08 — Convolutional Neural Networks (CNN) & Computer Vision**
- Introduction to Computer Vision and Image Tensors
- Convolution, Filters, Kernels, Padding, and Stride
- Pooling Layers
- CNN Architectures and Image Classification

**Section 09 — RNN, LSTM, Attention & Transformers**
- Sequential Data and Recurrent Neural Networks (RNNs)
- The Vanishing Gradient Problem
- LSTM and GRU Architectures
- Attention Mechanism, Self-Attention, and Positional Encoding
- Transformer Architecture and Multi-Head Attention

⚙️ Installation and Setup Guide
To run the code and notebooks in this repository locally, follow these steps:

Step 1 — Clone the repository

bash
git clone https://github.com/mrniriteachai-eng/DEEP-LEARNING-MASTERCLASS.git
cd DEEP-LEARNING-MASTERCLASS
Step 2 — Create a virtual environment
Windows:

bash
python -m venv venv
venv\Scripts\activate
macOS / Linux:

bash
python3 -m venv venv
source venv/bin/activate
Step 3 — Install dependencies
If a requirements.txt file is present, run:

bash
pip install -r requirements.txt
(If not present, you will need to manually install the core libraries: pip install torch torchvision numpy pandas matplotlib jupyter)

Step 4 — Run Jupyter Notebook

bash
jupyter notebook
Navigate to the desired folder, open the .ipynb file, and run the cells sequentially.

Implement Gradient Descent and use advanced optimizers like Adam.

Build and train Neural Networks using PyTorch.

Understand how Convolutional Neural Networks (CNNs) process images.

Grasp the concepts of Recurrent Neural Networks, LSTMs, and the Attention Mechanism used in Transformers.
